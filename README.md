# Sparnod Rotation

A three-day full-body rotation (A / B / C) for the Sparnod SHG-10000 home gym, as an installable phone page: guided sessions with warm-up, rest countdowns and cool-down, exercise animations, set logging and a history calendar.

Live: https://wan292.github.io/home-gym/

- `program.json` — the plan (days, exercises, stations, sets, reps, cues)
- `src/index.html` — page template
- `build.py` — embeds the exercise frames and writes `index.html` + `docs/` (GitHub Pages, PWA)

Exercise animations are from [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain), the library [Lyftr](https://github.com/Cawlumm/lyftr) serves through open-exercise-db. Workout logs are stored on the phone only; nothing personal is in this repo.
